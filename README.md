# Smart-Watt
SMARTWATT – Electricity Billing System

## Project Overview

SMARTWATT is a Python-based electricity billing system that calculates electricity bills using slab-wise rates, fixed charges, and tax. It also provides basic electricity consumption analysis.

## Features

- Consumer name input.
- Automatic slab-wise bill calculation.
- Fixed charge and 5% tax calculation.
- Formatted electricity bill receipt.
- Electricity usage analysis.
- Electricity-saving suggestions.
- Invalid input handling.

## Tariff Structure

Units| Rate
First 100 units| Rs. 3/unit
Next 100 units| Rs. 5/unit
Above 200 units| Rs. 8/unit

Fixed Charge: Rs. 50
Tax: 5%
